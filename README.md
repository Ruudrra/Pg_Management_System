🏠 Hostel / PG Management System
A Java-based web application developed to automate hostel and PG management tasks. The system replaces manual record keeping with a digital platform for managing students, rooms, fees, and complaints efficiently.
Built using Servlets, JSP, JDBC, and MySQL following the MVC architecture, the system provides secure login and organized management for administrators and students.
✨ Features
🔐 Secure Admin & Student Login (Session Management)
👨‍🎓 Student Management
🛏️ Room Allocation & Management
💰 Fee Management
📢 Complaint Submission System
🚪 Logout & Session Handling
🎨 Clean UI with CSS and Side Navigation
